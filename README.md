# 서적부 POS (Book Store POS)

사업자 등록 없이 운영하는 서점용 웹 포스기입니다. 일반 포스기를 쓸 수 없는 환경에서
버튼 클릭만으로 **재고 차감·매출 집계**가 자동으로 되고, 여러 사람이 **실시간으로 함께** 사용할 수 있습니다.

👉 https://keonchue.github.io/seojeokbu-pos/

## 기능
- 판매(계좌이체/현금), 실수령액·차액 기록 (실제 금액과 장부 불일치 대응)
- 할인 (원 / % 전환)
- 반품 (부분 반품 지원)
- 재고 관리 (입고/수정/삭제, 결제수단별 판매 집계)
- **재고 변동 이력** — 입고·판매·반품·조정·가격변경을 전부 원장에 기록
- 매출 내역 + CSV 내보내기
- **리포트** — 기간별 매출, 일/월별 그래프, 책별 판매 순위, 기간 CSV
- **백업 / 복원** — 전체 데이터를 JSON 파일로 저장하고 되돌리기
- **휴대폰·태블릿 지원** + 홈 화면에 설치되는 앱(PWA), 오프라인에서도 실행
- Firebase 실시간 동기화 + 로그인(가게 공용 계정)

## 기술
- 단일 `index.html` (프레임워크 없음)
- Firebase Authentication + Firestore (실시간, 오프라인 지원)
- 서비스워커(`sw.js`)로 앱 껍데기 캐시 → 인터넷/CDN 장애에도 화면은 뜸

## 데이터 구조 (Firestore)
| 컬렉션 | 내용 |
|---|---|
| `books` | 책 정보와 현재 재고 (`increment()`로 원자적 차감) |
| `transactions` | 판매·반품 기록 (`type:'return'`이 반품) |
| `stockLogs` | 재고·가격 변동 원장 (입고/판매/반품/조정/등록/삭제/가격변경) |
| `meta` | 최초 세팅 플래그 |

`stockLogs` 기록은 판매 batch와 **분리된 별도 쓰기**입니다.
기록이 실패해도 판매 자체는 절대 막히지 않게 하기 위함입니다.

## 실행
정적 웹 호스팅(GitHub Pages 등)에 올려서 사용합니다.
로컬 테스트 시에도 `file://` 이 아닌 웹서버로 열어야 합니다.

```
npx http-server -p 5178 -c-1
# → http://localhost:5178
```

## 배포
1. **먼저** `firestore.rules` 를 Firebase 콘솔 → Firestore → 규칙에 붙여넣고 게시
   (git push로는 규칙이 배포되지 않습니다)
2. `main` 브랜치에 push → GitHub Pages 자동 재배포

그게 전부입니다. 서비스워커가 우리 파일을 **항상 네트워크 우선**으로 가져오기 때문에
배포할 때 캐시 버전을 올리는 등의 수동 작업이 필요 없습니다.
(캐시는 인터넷이 안 되거나 3.5초 안에 응답이 없을 때만 쓰는 예비품입니다)

## 앱으로 설치하기
- **아이폰·아이패드**: Safari로 접속 → 공유(⬆) → 홈 화면에 추가
- **안드로이드**: Chrome 메뉴(⋮) → 앱 설치
- **PC**: 주소창 오른쪽 설치(⊕) 아이콘, 또는 앱 안 ⚙ 설정 → 홈 화면에 설치하기

## 설정 파일
- `firebase-config.js` : Firebase 웹 설정 (공개돼도 되는 값)
- `firestore.rules` : 보안 규칙 (가게 계정만 접근 허용) — Firebase 콘솔에 게시
- `manifest.json` / `sw.js` / `icon-*.png` : 앱 설치·오프라인용
- `SETUP-firebase.md` : Firebase 초기 설정 안내
